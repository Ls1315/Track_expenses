# 記帳 PWA

免費、不用上架的 iPhone 記帳工具。v0.2 起資料存在 Firebase（Google 的雲端資料庫），用 Google 帳號登入，可以跨裝置、和家人共用；沒網路時也能記，連上線後自動同步。

## 功能（v0.2.0）
- 登入：Google 帳號
- 個人帳／家庭帳分開：記帳畫面切換「只有我」或「家庭共用」，會記住上次選擇；明細和報表可篩選 全部／個人／家庭
- 家庭：設定 → 建立家庭 → 把 8 碼邀請碼給家人，家人在設定 →「用邀請碼加入」；可換新邀請碼、離開家庭
- 家庭帳的每一筆會標示是誰記的；家庭報表多一個「誰記的」統計；名字預設是 Google 帳號名稱，可在設定 →「改我的名字」修改（舊紀錄也會跟著更新）
- 分類每個人各自一份，互不影響
- 從 v0.1 搬資料：在 v0.1 匯出 CSV，在 v0.2 設定 →「匯入 CSV」，可選匯入到個人帳或家庭帳

## v0.1 就有的功能
- 記帳：自訂數字鍵盤輸入金額 → 點分類就儲存；可選日期、備註（可寫 #標籤）；4 秒內可復原
- 常用組合：近 90 天出現 2 次以上的「分類＋金額」會變成一鍵按鈕
- 明細：依月份、依日期分組；點一筆可編輯／刪除
- 分類分兩層：主分類底下可以有子分類（例如「餐飲」底下有早餐、午餐），主分類本身也能直接記帳
- 報表：可切換「月／年／近半年／自訂起訖日」；總支出、平均（月、自訂看日平均，年、近半年看月平均）、和上一期比較；年、近半年、跨月的自訂期間有每月長條圖（點長條切到那個月）；各主分類金額與占比，點主分類可展開看子分類
- 設定：主分類／子分類新增、改名、排序、刪除、移動；CSV 匯出（分享選單存到「檔案」）與匯入（同 id 會覆蓋，不會重複）；也能匯入電子發票平台的消費明細 CSV

## Firebase 設定（第一次要做）
主控台網址：https://console.firebase.google.com/ 。以下按鈕名稱依撰寫時的介面，若有不同以畫面為準。
1. **建立專案**：「新增專案」→ 取名 → Google Analytics 可以關掉（用不到）。方案維持免費的 Spark。
2. **註冊網頁 App**：專案總覽 → 新增應用程式 → 選網頁圖示 `</>` → 取暱稱；「Firebase Hosting」不用勾。完成後畫面會顯示 `firebaseConfig = { apiKey: ..., authDomain: ..., projectId: ..., ... }`。
3. **開啟 Google 登入**：Authentication → 開始使用 → 登入方式（Sign-in method）→ Google → 啟用 → 選一個專案支援電子郵件 → 儲存。
4. **授權網域**：Authentication → 設定（Settings）→ 授權網域（Authorized domains）→ 新增 `<你的帳號>.github.io`（只填網域，不含 https:// 和 repo 路徑）。本機測試用的 `localhost` 預設已在清單中。
5. **建立 Firestore**：Firestore Database → 建立資料庫 → 位置建議選 `asia-east1`（台灣）；**位置建立後不能改**。選「正式版模式（production mode）」。
6. **貼上安全規則**：Firestore Database → 規則（Rules）→ 把 repo 裡 `firestore.rules` 的內容整個貼上 → 發布。**沒做這步，App 會讀寫失敗。**
7. **把設定值放進程式**：把步驟 2 的 `firebaseConfig` 物件貼進 `firebase-config.js`，取代 `null`。這些值不是機密，可以放在公開 repo；資料安全由步驟 6 的規則把關。

以後如果修改了 `firestore.rules`，要再貼到主控台發布一次才會生效。

## 部署到 GitHub Pages（免費）
1. 在 GitHub 建一個新 repo，把這個資料夾的檔案全部推上去
2. repo 的 Settings → Pages → Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`
3. 等 1～2 分鐘，網址是 `https://<你的帳號>.github.io/<repo名稱>/`

## 安裝到 iPhone
1. 用 **Safari** 打開上面的網址
2. 點分享按鈕 →「加入主畫面」
3. 之後都從主畫面的圖示開啟（在 Safari 分頁裡用的資料是分開的，也可能被清除）

## 更新版本
改完程式後，把 `sw.js` 裡的 `CACHE = 'ledger-vN'` 版本號 +1 再推上去，否則手機會繼續用舊的快取。
Firebase SDK 放在 `vendor/firebase/`，升級方式見該資料夾的 README。
更新後要完全關掉 App 再重開，可能要開兩次才會看到新版。

## 本機測試
```
python3 -m http.server 8000
```
然後打開 http://localhost:8000

## 已知限制
- 只記支出，沒有收入、帳戶、預算
- 金額只能是整數（新台幣）
- 加入家庭需要連網；其他操作離線也能做
- 每次開 App 會從雲端讀一次全部紀錄。Firebase 免費方案每天 5 萬次讀取，一般家庭用量應該夠，紀錄非常多時要注意
- 別人記的家庭帳可以修改、刪除，但刪除後無法復原
