# 記帳 PWA

免費、不用上架的 iPhone 記帳工具。資料存在手機本機（IndexedDB），不會上傳到任何伺服器。

## 功能（v0.1.0）
- 記帳：自訂數字鍵盤輸入金額 → 點分類就儲存；可選日期、備註（可寫 #標籤）；4 秒內可復原
- 常用組合：近 90 天出現 2 次以上的「分類＋金額」會變成一鍵按鈕
- 明細：依月份、依日期分組；點一筆可編輯／刪除
- 報表：月總支出、日平均、上月總額、各分類金額與占比
- 設定：分類新增／改名／排序／刪除；CSV 匯出（分享選單存到「檔案」）與匯入（同 id 會覆蓋，不會重複）

## 部署到 GitHub Pages（免費）
1. 在 GitHub 建一個新 repo，把這個資料夾的檔案全部推上去
2. repo 的 Settings → Pages → Source 選 `Deploy from a branch`，分支選 `main`、資料夾選 `/ (root)`
3. 等 1～2 分鐘，網址是 `https://<你的帳號>.github.io/<repo名稱>/`

## 安裝到 iPhone
1. 用 **Safari** 打開上面的網址
2. 點分享按鈕 →「加入主畫面」
3. 之後都從主畫面的圖示開啟（在 Safari 分頁裡用的資料是分開的，也可能被清除）

## 更新版本
改完程式後，把 `sw.js` 裡的 `CACHE = 'ledger-vN'` 版本號 +1 再推上去，否則手機會繼續用舊的快取。
更新後要完全關掉 App 再重開，可能要開兩次才會看到新版。

## 本機測試
```
python3 -m http.server 8000
```
然後打開 http://localhost:8000

## 已知限制
- 只記支出，沒有收入、帳戶、預算
- 金額只能是整數（新台幣）
- 不會在不同裝置之間同步，請定期匯出 CSV 備份
